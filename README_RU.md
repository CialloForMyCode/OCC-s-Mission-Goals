# OCC's Mission & Goals

Инструмент отслеживания обновлений / исправлений для ONC Compiler Collection, созданный для упрощения процесса управления задачами и повышения эффективности. Два режима: GUI на WPF и CLI с выводом стандартного JSON для AI / скриптов / CI.

# Установка

### Требования

- Windows 10 / 11
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### Сборка

```bash
git clone https://github.com/CialloForMyCode/OCC-s-Mission-Goals.git
cd "OCC-s-Mission-Goals"
dotnet build
```

### Запуск

```bash
# Режим GUI
dotnet run

# Режим CLI (показать справку)
dotnet run -- -h
```

Никаких сторонних NuGet зависимостей — чистый .NET 8 + WPF, готовый к использованию.

# Использование

### Основной процесс

1. **Создать проект** — Меню → Новый проект (`Ctrl+N`): задать имя, описание, начальную версию
2. **Создать версию** — Диалог версий для итерации номера (например `0.1.0-alpha.1` → `0.1.0-alpha.2`)
3. **Добавить записи** — Панель инструментов → Новая запись: заголовок, серьёзность, срок, связанные файлы и т.д.
4. **Отслеживание** — Просмотр и управление записями на странице «Незавершённые»
5. **Завершение и архивация** — После отметки выполнения записи появляются на странице «Завершённые». Когда все записи версии завершены — архив в один клик.

### Страницы

| Страница | Назначение |
|----------|------------|
| Панель | Диаграмма распределения серьёзности, тренды и обзор проекта |
| Незавершённые | Все активные записи, сгруппированные по версиям: поиск, сортировка, редактирование, завершение, удаление |
| Завершённые | Завершённые записи по версиям: отмена, редактирование, удаление; архивация при полном завершении версии |
| Расширения | Управление плагинами / расширениями |
| Справка | Полное руководство: операции, горячие клавиши, поля, CLI-справочник |

### Сортировка

Панель инструментов предлагает 7 режимов сортировки:

| Сортировка | Описание |
|------------|----------|
| Серьёзность ↑ | Fatal → Update |
| Серьёзность ↓ | Update → Fatal |
| Срок ↑ | Раньше → Позже |
| Срок ↓ | Позже → Раньше |
| Версия ↑ | По алфавиту версий |
| Версия ↓ | Обратный порядок версий |
| Только избранное | Только избранные записи, по серьёзности |

### Уровни серьёзности

| Значение | Описание |
|----------|----------|
| `Fatal` | Критический, немедленное действие |
| `Severe` | Высокий приоритет |
| `General` | По умолчанию |
| `Patch` | Мелкое исправление |
| `Update` | Обновление функционала |

### Хранение данных

Все данные хранятся в `Projects/` рядом с исполняемым файлом:

```
Projects/
└── <ИмяПроекта>/
    ├── project.json              # Метаданные проекта
    └── versions/
        ├── 0.1.0-alpha.0.json    # Файлы версий
        ├── 0.2.0-alpha.0.json
        └── archive/              # Архивные версии
```

ID записей в формате `PPPEEEEEE` (9 цифр): первые 3 — номер проекта, последние 6 — автоинкремент.

### Два режима

Приложение проверяет аргументы запуска в `Main`: без аргументов — **GUI режим** (окно WPF); с аргументами — **CLI режим** (консоль с JSON выводом).

# CLI команды

Режим CLI создан для AI / скриптов / CI. Весь вывод — JSON в stdout; ошибки — в stderr.

```
OCCMissionGoals.exe [-p <проект>] [-v <версия>] <команда> [аргументы]
```

### Команды записей

| Команда | Коротко | Длинно | Аргументы | Описание |
|---------|---------|--------|-----------|----------|
| Добавить | `-a` | `--add` | `{Title="...", Severity="Fatal", ...}` | Добавить запись в JSON или упрощённом `Key="Value"` синтаксисе |
| Просмотр | `-c` | `--check` | `<id>` | Полная информация о записи (JSON) |
| Завершить | `-d` | `--done` | `<id>` | Отметить запись как завершённую |
| Отменить | `-u` | `--undone` | `<id>` | Вернуть в незавершённые |
| Удалить | `-D` | `--delete` | `<id>` | Удалить запись (безвозвратно) |
| Избранное | `-f` | `--favorited` | `<id> true\|false` | Установить статус избранного |
| Список | `-l` | `--list` | — | Показать все записи (JSON массив) |

### Команды версий (`-v`)

| Использование | Описание |
|---------------|----------|
| `-v <версия>` | Переключиться на указанную версию |
| `-v Iterate` | Увеличить номер итерации (напр. `alpha.0` → `alpha.1`) |
| `-v Delete <версия>` | Удалить файл версии (нельзя удалить текущую) |
| `-v Archive <версия>` | Архивировать версию в `versions/archive/` (требуется завершение всех записей; нельзя архивировать текущую) |

### Глобальные опции

| Флаг | Описание |
|------|----------|
| `-p <имя>` / `--project <имя>` | Выбрать целевой проект |
| `-v <версия>` | Выбрать целевую версию (с командами записей) |
| `help` / `-h` / `--help` | Показать справку |

### Формат добавления записи

```
-a {Title="ИсправитьБаг", Severity="Fatal", Brief="Кратко", Detail="Подробно",
    IsFavorited=false, Version="0.1.0", Type=["Bug"],
    RelatedFiles={"C:\\src\\App.cs"=[25,10,"App.Init"]}}
```

Обязателен только `Title`. `Severity` по умолчанию `General`. `Type` — массив строк, `RelatedFiles` — путь → `[строка, столбец, функция]`.

### Примеры

```bash
# Список всех записей проекта "ONC"
OCCMissionGoals.exe -p ONC -l

# Добавить критический баг
OCCMissionGoals.exe -a {Title="NullRef краш", Severity="Fatal", Brief="Краш при старте", Version="0.1.0-alpha.0", Type=["Bug"], RelatedFiles={"C:\\src\\App.cs"=[25,10,"App.Init"]}}

# Отметить как выполненное
OCCMissionGoals.exe -d 001000001

# Сменить версию и добавить запись
OCCMissionGoals.exe -v 0.2.0-alpha.0 -a {Title="Добавить вход", Severity="Update"}
```

### Технологии

- **Рантайм**: .NET 8
- **UI**: WPF (Windows Presentation Foundation)
- **Формат данных**: JSON (System.Text.Json)
- **Формат конфига**: INI
- **Сторонние зависимости**: отсутствуют

### Модель данных

```
project.json          →  ProjectConfig (Name, Description, CurrentVersion, ProjectNumber)
versions/*.json       →  DataFile (User, Unfinished[], Finished[])
Каждая запись         →  GoalEntry
```

Поля записи:

| Поле | Тип JSON | Описание |
|------|----------|----------|
| `Id` | `string` | Скрытый ID `PPPEEEEEE` (9 цифр) |
| `Title` | `string` | Заголовок (обязательное) |
| `Severity` | `string` | Fatal / Severe / General / Patch / Update |
| `Brief` | `string` | Краткое описание |
| `Detail` | `string` | Подробное описание |
| `Deadline` | `[год,месяц,день]` | Срок выполнения |
| `CompletedAt` | `[год,месяц,день]` | Дата завершения |
| `ChangeDemand` | `int` | Счётчик изменений |
| `IsFavorited` | `bool` | Избранное |
| `Version` | `string` | Версия |
| `Type` | `string[]` | Теги типов (Bug, UI, Feature и т.д.) |
| `RelatedFiles` | `{путь: [строка,столбец,функция]}` | Связанные файлы |
