🚀 快速入门

1新建或打开项目 — 点击菜单 项目 → 新建项目 或 打开项目
2新建条目 — 使用 Ctrl+N 或菜单 条目 → 新建条目
3管理版本 — 通过菜单 文件 → 新建数据文件 创建版本快照

⌨️ 快捷键

Ctrl按住显示菜单栏和控制按钮
Ctrl+N新建条目
Ctrl+F聚焦搜索框，按标题过滤条目
Ctrl+1切换到日志页
Ctrl+2切换到未完成页
Ctrl+3切换到已完成页
Ctrl+4切换到展开视图
Ctrl+Wheel缩放条目字体大小

📑 页面说明

📊 日志 (Log)

总览页面，显示统计信息、热点类别和最近条目。用彩色进度条展示未完成 / 已完成的占比。

📝 未完成 (UnDone)

列出所有未完成条目。支持排序、搜索过滤、收藏星标。点击条目展开详情，双击编辑。

✅ 已完成 (Done)

列出所有已完成条目。可以撤销完成状态移回未完成列表。

🔍 展开视图 (Expand)

合并显示所有条目，自动展开全部详情，适合全局搜索和审阅。

🏷️ 严重程度

每个条目可标记一个严重程度，用于优先级排序：

🔴 致命 🔴 严重 🔴 一般 🔴 补丁 🔵 更新

🗂️ 版本管理

每个项目支持多版本数据文件。新建版本时会从当前版本分支出去，各版本独立维护。

通过 文件 菜单可以：

  • 新建数据文件 — 基于当前版本创建新版本分支
  • 打开数据文件 — 切换到已有版本

💻 命令行

支持命令行操作，在终端中运行：

OCCMissionGoals.exe --help

可用于自动化脚本、CI/CD 集成等场景。
